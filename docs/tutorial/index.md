# Tutorial

The author's tour: twelve chapters that take you from a first panel to a printed comic,
one part of the language at a time. Work through them in order. A reader who finishes can
write any example in the [gallery](../gallery.md), and the chapters follow the gallery's
own groups, so each chapter ends by opening its group in the playground.

Every chapter has the same parts:

- **What you will make**, as a picture;
- the **complete documents**, which you save and build;
- **what the compiler decided**, and why;
- **Try it**: the chapter's examples, opened in the playground;
- **Check it**: a `scenet check` step;
- **what you learned**, and **where to go next**.

Nothing is assumed except that you can type a file and run a command, or open the
[playground](https://creatoan.github.io/scenet/playground/) in a browser.
