# Learn Scenet from Python

The developer's track: five chapters that take you from `pip install scenet` to using
Scenet inside a program of your own, with confidence. Work through them in order.

Every chapter has the same parts:

- **What you will build**;
- **complete examples**, each a script with its imports, and what it prints, word for word;
- **what you learned**, and **where to go next**.

Every example runs as it is shown: the test suite saves each one to a file of its own, in a
folder holding the documents its chapter saved, runs it, and compares what it prints with
the page. Each chapter links the pages of [the Python reference](../../reference/api/index.md)
for the names it uses.

Nothing is assumed except that you can write a Python script and run it. The documents the
examples compile are written in Scenet's language, which [the author's tour](../index.md)
teaches; you can read this track without it.
