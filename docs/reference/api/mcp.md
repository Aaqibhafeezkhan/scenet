# Agent-facing surface

The MCP server and the spec pack it serves. See [the MCP server reference](../mcp.md) for the
tools as a client sees them, and [driving Scenet from a model](../../howto/drive_from_a_model.md)
for connecting one.

`scenet.mcp` needs the optional extra, `pip install 'scenet[mcp]'`; `scenet.spec_pack` does not.
