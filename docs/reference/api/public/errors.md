# Errors

Every error a public function raises is one of these, and a {py:exc}`~scenet.errors.ScenetError`: `except ScenetError` catches them all. Each also keeps the built-in exception it would have been, so `except ValueError` keeps working. See {py:mod}`scenet.errors` for what the promise covers.
