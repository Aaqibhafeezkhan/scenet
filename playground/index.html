A semantic DSL for comic panels, compiled to SVG. Deterministic geometry — no generative image model. The compiler below is the same Python that runs on the command line, executing in your browser under WebAssembly. Letter over your own art, in colour, and export the staging for image models.

⚠️ This project is deliberately AI-generated. It exists as a personal training ground for learning to work with AI coding tools — an experiment first, a usable tool second.
